# Chit-Chat-Application
This ChitChat Application is areal time web application that allows instant and bidirect messages between users The app features four customizable themes and supports inline image uploads, a quick emoji picker, and real-time typing indicators.
All rich features include:
Instant bidirectional text messaging powered by WebSockets (`Flask-SocketIO`).
  - You can choose from 4 custom UI themes in real-time:
  - **WhatsApp Green** (Default)
  - **Ocean Blue**
  - **Sunset Pink**
  - **Midnight Dark**
You can upload and share images directly in the chat feed via base64 encoding.
It shows real-time feedback showing when another user is actively typing.
You can add emojis directly into your message input field.
You can delete sent messages for all users in real-time.
It automatically retains up to the last 50 messages and tracks connected user count.
It auuto-generates user avatars based on the entered username.
